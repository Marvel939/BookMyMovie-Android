# BookMyMovie - Android Application

Welcome to the **BookMyMovie** repository! This is a complete movie booking system built with modern Android technologies.

## 🚀 Getting Started

**BookMyMovie** allows users to explore the latest movies, book tickets, order food, and even purchase/rent digital titles for home streaming. 

Built with **Jetpack Compose** and **Kotlin**, the app offers a fluid and responsive user experience, while **Firebase** powers the backend with real-time updates and secure authentication.

## 🛠️ Tech Stack

- **UI Framework**: Jetpack Compose (Kotlin)
- **Architecture**: MVVM (Model-View-ViewModel)
- **Backend**: Firebase (Auth, Firestore, Realtime DB, Cloud Functions)
- **Payments**: Stripe SDK
- **Animation**: Compose Animations & Lottie
- **Analytics**: Vico (Bar Charts)
- **AI Integration**: Google Gemini LLM via Firebase Functions
